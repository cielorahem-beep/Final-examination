                              LOGO SETUP
================================================================================

Files to modify: ALL HTML FILES (index.html, products.html, product-details.html, about.html)

WHAT TO DO:
1. Save your SPUD logo as: "logo.png" (or .jpg, .gif, .svg)
2. Place it in the SAME FOLDER as your HTML files
3. The HTML is already configured to display it!

The logo will appear:
- In the navigation bar on the LEFT side
- In a circular container (50x50 pixels)

RECOMMENDED LOGO SIZE: 200x200 pixels or larger (it will scale down)
RECOMMENDED FORMAT: PNG with transparent background for best results

================================================================================
                      IMAGE OPTIMIZATION TIPS
================================================================================

For best performance:
• Keep image file sizes under 500KB each
• Use JPG for photographs (better compression)
• Use PNG for your logo (transparency support)
• Recommended resolution: 1920 pixels wide for background images
• All images support the parallax scrolling effect

Image Naming Rules:
✓ Use lowercase filenames
✓ No spaces in filenames
✓ Use hyphens (-) instead of underscores (_)
✓ Match the exact names specified above

================================================================================
                    CUSTOMIZATION OPTIONS
================================================================================

Want to change overlay opacity or colors?

1. HERO OVERLAY: Edit index.html, find the hero section:
   style="background-image: url('hero-bg.jpg'); ..."
   The gray overlay is set to 35% opacity

2. ABOUT OVERLAY: 92% white overlay (keeps text readable)

3. PRODUCTS OVERLAY: 93% white overlay

To change overlay opacity, modify the CSS in style.css:
   Look for ".hero-overlay { background: rgba(0, 0, 0, 0.35); }"
   Change the 0.35 to a different value:
   - 0 = fully transparent (image fully visible)
   - 0.5 = 50% transparent
   - 1 = fully opaque (image not visible)

================================================================================
                         TROUBLESHOOTING
================================================================================

Images not showing?
   ✓ Check filename spelling (must match exactly)
   ✓ Make sure files are in the correct folder
   ✓ Refresh your browser (Ctrl+F5 or Cmd+Shift+R)
   ✓ Check the browser console for error messages

Logo not showing?
   ✓ Ensure logo.png exists in the folder
   ✓ Try different image formats: .jpg, .svg, .gif
   ✓ Check that image dimensions are square (for best appearance)

Background images look blurry?
   ✓ Use higher resolution images (1920+ pixels wide)
   ✓ Reduce image compression
